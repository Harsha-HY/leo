# Praja Pragati Trust (PPT) — Official Web Platform

[![React](https://img.shields.io/badge/React-18-blue.svg)](https://react.dev/)
[![Tailwind CSS](https://img.shields.io/badge/TailwindCSS-3.4-38bdf8.svg)](https://tailwindcss.com/)

[![License](https://img.shields.io/badge/Trust_Regd-24%2F83-green.svg)](https://pptindia.org)

An interactive, spatial 3D web platform engineered for **Praja Pragati Trust (PPT)**, a grassroots non-profit organisation established in 1983 in Tirupati, Andhra Pradesh, dedicated to tribal welfare, child protection, sustainable agriculture, and the abolition of bonded labour across South India.

---

## 🌟 Key Features

1. **Trending 3D Panel Layouts & Spatial Design**:
   - **Trending 3D Hero Stage**: Interactive perspective camera tracking with live "3D Layer Mode" exploded perspective and floating holographic metric satellites.
   - **3D Transformation Lens**: Interactive before-and-after split-lens comparing real casework transformations (Debt-bondage to freedom, toxic chemical debt to 1,351+ acres natural farming, tribal marginalization to RoFR land titles).
   - **3D Bento Grid (Impact Matrix)**: Asymmetric bento panels including a 41-year milestone scrubber (1983–2026), live resource allocation progress bars, compliance vault, and active radar corridors.
   - **3D Cylindrical Orbiting Project Deck**: Spatial 360-degree cylindrical carousel featuring PPT flagship interventions.
   - **Interactive 3D Tilt Cards (`TiltCard`)**: Physics-based perspective tilt (`rotateX`/`rotateY`) with dynamic specular glare light sweeps and floating z-depth layers.

2. **Multilingual System (4 Languages)**:
   - Full-website dynamic translation engine for **Telugu (తెలుగు)**, **Tamil (தமிழ்)**, **Hindi (हिन्दी)**, and **English**.
   - Translates all cards, descriptions, modals, navigation links, and animated typewriter keywords.

3. **Multi-Mode Visual Engine**:
   - 4 aesthetic modes with instant dynamic theme switching:
     - **Mode 01**: Clean Studio
     - **Mode 02**: Emerald Ecology (Grama Swaraj)
     - **Mode 03**: Sapphire Justice (Constitutional Rights)
     - **Mode 04**: Midnight Obsidian (Luxury Dark)

4. **Institutional Statutory Vault & Governance**:
   - Complete statutory documentation:
     - **Trust Deed**: Regd. No. 24/83 under Indian Trusts Act 1882 (Machilipatnam)
     - **Section 80G**: Tax exemption under IT Act (AAATP8682K25HY02)
     - **Section 12A**: Permanent exemption (AAATP8682K25HY01)
     - **FCRA**: Ministry of Home Affairs Regd. 010140011 (Valid to 2028)
     - **MCA CSR-1**: Regd. CSR00017363
     - **NITI Aayog**: NGO Darpan AP/2013/0068300
   - One-click Canara Bank transfer copy box for direct 80G donations.
   - Annual reports reading room with executive summaries and PDF downloads.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Harsha-HY/leo.git
cd leo

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Compile and optimize for production
npm run build

# Preview production build locally
npm run preview
```
